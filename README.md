# 2027 대학입시 전략실 PRO v6

## 기능
- 기존 v5 성적·논술·정시·백업 기능 보존
- 서울·경기·인천 42개 대학을 대상으로 인문·사회 분야 **탐색 키워드** 자동 생성
- 지역·전공·대학명 필터, 성적표 백분위 참고 표시
- 사용자가 검증한 동일 기준 3개년 이상 70%컷이 있는 대상만 1~10 지원 여유도 표시
- 공식 자료 미확보 항목은 **판정 보류**. 임의 합격선이나 가짜 합격률 없음

## 반드시 알아둘 한계
이 버전의 대학·학과 조합은 실제 2027 모집단위 검증 명단이 아닌 **탐색 후보**입니다. 학과 존재·정시 모집군·반영식은 공식 모집요강 확인이 필요합니다. 전국 대학 공식 입시결과를 자동 수집하는 기능은 구현되지 않았습니다. 1~10점은 합격 확률이 아닙니다. 사용자가 '검증' 체크한 자료를 앱이 독립적으로 검증하지는 않습니다.
