# 2027 대학입시 전략실 PRO — 배포판

## 설치
GitHub `jusuk717/admission-2027` 저장소 루트에 이 ZIP 내부의 **파일 전체**를 업로드하고 Commit changes. GitHub Pages 주소: https://jusuk717.github.io/admission-2027/ . 기존 앱에서 먼저 백업하세요.

## 구현
성적 저장/조회, 문과·이과/지역 선택, 2026 학과별 공개 정시 70%컷 발췌 표본 비교, 1~10점 신호등 참고 지표, 논술 관심대학, 정시 가/나/다군 메모, JSON 백업/복원, PWA 아이콘/오프라인 캐시.

## 중요 제한
- 학과별 2026 공개 입결 중 일부 **표본**만 내장. 서울·경기권 전체 및 3개년 데이터 완전 구축 아님.
- 단순 4과목 백분위 평균과 과거 70%컷 비교로, 대학별 2027 환산식, 영어 등급, 탐구 가중치, 수학 가산점, 지원 자격 등을 미반영. **합격 확률이나 검증된 예측 모델이 아님.**
- 신호등 기준: 차이 +5 이상 초록, -4~+4 노랑, -5 이하 빨강. 임시 참고 기준으로 실제 적중률 검증되지 않음.
- 데이터 출처: https://neungmun.com/admissions/jungsi/ (2026학년도 정시 공개 결과를 어디가 자료 기반으로 재정리한 페이지), 확인 2026-11-17.
- 실제 지원 전 https://www.adiga.kr/ 와 대학별 2027 모집요강 필수 확인.
- 기존 v6/v8의 로컬 저장 형식과 다를 수 있음. v8 성적은 자동 이전 시도, v6는 백업 후 수동 재입력 권장.
