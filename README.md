# 2027 대학입시 전략실 PRO v5

GitHub Pages용 정적 PWA. ZIP을 풀고 **내용물 전체**를 저장소 최상위에 업로드하세요. 기존 저장 데이터는 브라우저 localStorage에 유지되지만 업로드 전 JSON 백업을 권장합니다.

## 기능
- 수능 등급·표준점수·백분위 입력
- 논술 시험 일정 및 체크리스트
- 정시 가/나/다군 지원 메모
- 대학·학과별 공식 입결 근거 등록 및 1~10 지원 여유도 표시
- 검증된 자료가 있는 대학만 자동 정렬하는 대학 추천 탭
- 아이폰 아이콘(180/192/512), 오프라인 PWA, JSON 백업·복원

## 중요한 한계
- **전국 대학의 공식 입시 결과 DB를 사전 탑재하지 않았습니다.** 현재는 대학별 환산점수와 입결을 사용자가 확인·입력해야 합니다.
- 1~10은 실제 합격 확률이 아니라 과거 동일 지표 컷 대비 상대 지수입니다.
- 입시 자료의 공식 여부는 앱이 자동 검증하지 않습니다. 사용자의 검증 체크에 의존합니다.
- 논술 최저학력기준은 대학별 복잡한 반영 규칙이 있어 자동 판정하지 않습니다.
- 동일 전형·동일 지표·동일 계산 기준으로 3개년 이상의 70%컷을 입력한 경우에만 지수가 표시됩니다.
- 수시 합격자의 정시 지원 제한 및 대학별 2027 모집요강을 반드시 확인하세요.
